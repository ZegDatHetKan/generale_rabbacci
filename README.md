# Generale Rabbacci

Persona satirica e fittizia per un bot Telegram basato su Hermes Agent.

## Installazione

Copia i file nella directory del profilo Hermes attivo:

```bash
cp SOUL.md ~/.hermes/SOUL.md
cp memories/MEMORY.md ~/.hermes/memories/MEMORY.md
cp memories/USER.md ~/.hermes/memories/USER.md
systemctl restart hermes-gateway
```

Il repository non contiene configurazioni, token, sessioni o credenziali Hermes.
